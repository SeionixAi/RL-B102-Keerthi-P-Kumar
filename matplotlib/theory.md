## What is Matplotlib?

Matplotlib is a Python library used for data visualization. It helps in creating graphs such as line plots, bar charts, and scatter plots.

### Why it is used

- To understand data visually
- To analyze patterns and trends
- To help in decision making
- Widely used in AI/ML and data science

## Types of Plots

### Line Plot
Used to show trends over time or continuous data.

### Bar Plot
Used to compare different categories.

### Scatter Plot
Used to show relationship between two numerical variables.

### Key Difference
- Line → trend
- Bar → comparison
- Scatter → relationship

## Figure and Axes in Matplotlib

### Figure
The entire canvas or window where plots are drawn.

### Axes
The actual area where data is plotted.

### Key Idea
- Figure = full canvas
- Axes = individual plot inside the figure

Used for creating advanced visualizations and dashboards.

## Labels, Titles, and Legends

### Labels
Describe x-axis and y-axis.

### Title
Gives overall meaning to the graph.

### Legend
Explains multiple lines or datasets in the same plot.

### Importance
They make visualizations clear, readable, and meaningful.

## Importance of Data Visualization in AI

Data visualization helps understand data before building machine learning models.

### Benefits

- Understand patterns and trends
- Detect outliers and errors
- Analyze relationships between variables
- Check data distribution
- Improve data preprocessing decisions

### Key Idea
Better understanding of data leads to better AI model performance.
